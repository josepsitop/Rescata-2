# Rescata
Busca y guarda lo que WhatsApp esconde.

Comparte desde WhatsApp un video/foto enviado como documento. Rescata localiza el
archivo real que WhatsApp ya descargó y lo MUEVE a tu galería (carpeta "Rescata") o a
la carpeta que elijas, sin duplicarlo ni gastar espacio extra.

Requiere el permiso "Acceso a todos los archivos" (una sola vez) para poder mover.
Sin ese permiso solo puede copiar.

## Compilar
1. Sube todo este proyecto a un repositorio de GitHub (rama main).
2. Pestaña Actions -> "Compilar Rescata" (corre sola al subir).
3. Descarga Rescata.apk desde Releases.
4. Desinstala la versión anterior antes de instalar (cada compilación se firma distinto).
